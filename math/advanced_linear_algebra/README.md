
# Advanced Linear Algebra

This project implements advanced linear algebra operations
using Python and NumPy.

## Tasks

| File | Description |
| --- | --- |
| 0-determinant.py | Calculates the determinant of a matrix |
| 1-minor.py | Calculates the minor matrix |
| 2-cofactor.py | Calculates the cofactor matrix |
| 3-adjugate.py | Calculates the adjugate matrix |
| 4-inverse.py | Calculates the inverse of a matrix |
| 5-definiteness.py | Determines matrix definiteness |

## Concepts Covered

- Determinants
- Minors and cofactors
- Adjugate matrices
- Matrix inverses
- Eigenvalues
- Matrix definiteness

## Requirements

- Python 3
- NumPy
